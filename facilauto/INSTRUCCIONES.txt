FACIL AUTO — FIX FLASH DE LOGO v1.5.23

PROBLEMA

Al recargar con F5 podía aparecer durante un instante el logo enorme,
ocupando gran parte de la pantalla.

CAUSA

servicios-auth.js reemplaza el wordmark de texto por los PNG de marca.

El archivo:
assets/css/brand.css

se carga dinámicamente.

En una recarga normal podía existir un frame donde:
1. el <img> ya estaba insertado;
2. brand.css todavía no había terminado de aplicar;
3. el navegador usaba temporalmente el tamaño nativo del PNG.

El logotipo horizontal tiene una resolución nativa grande, por eso el
destello podía cubrir la pantalla.

CORRECCIÓN

Se agregan dos protecciones.

1. CSS CRÍTICO

Antes de insertar cualquier imagen de marca se crea en <head> un pequeño
<style id="fa-brand-critical"> con los tamaños esenciales.

Este CSS es síncrono y existe ANTES del primer frame del logo.

2. DIMENSIONES HTML

Las imágenes ahora nacen con width/height explícitos:

Logotipo desktop:
154 × 51

Isotipo mobile:
42 × 42

Logo footer:
86 × 65

Aunque por cualquier motivo el CSS externo tarde en cargar, el navegador
ya conoce un tamaño seguro desde el propio elemento HTML.

RESPONSIVE

Se mantiene:
- desktop: logotipo horizontal
- mobile <= 980 px: isotipo
- mobile pequeño: isotipo 36 × 36
- footer: logo completo

NO SE MODIFICA

- cálculos
- app.js
- seguros
- consultas
- créditos
- planes
- pagos
- Worker
- D1
- SQL

INSTALACIÓN

Subir:
- index.html
- servicios-auth.js

dentro de:
/facilauto/

Después hacer Ctrl + F5 una sola vez para tomar v1.5.23.

Las recargas normales posteriores con F5 ya no deben mostrar el flash.

VERSIÓN
v1.5.23
