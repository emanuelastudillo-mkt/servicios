QUÉ CAMBIA

Si una persona SIN SESIÓN completa una consulta y luego debe ingresar con Google,
los datos ya no se pierden.

Se guarda:
- Marca
- Modelo
- Versión
- Año
- Kilometraje
- Precio publicado / pactado
- Anticipo
- Plazo
- Tipo de comprador
- Seguridad de zona
- Jurisdicción
- Dólar de referencia

AL VOLVER DEL LOGIN

FACIL AUTO reconstruye los selects dependientes correctamente:

Marca
→ Modelo
→ Versión
→ Año

No intenta escribir un modelo o una versión antes de que app.js haya generado
sus opciones.

PÁGINAS SEO

Funciona también dentro de las calculadoras de páginas satélite.
Los campos ocultos o predefinidos por el perfil SEO no son forzados por el borrador.

CUÁNDO GUARDA

- al cambiar selects
- mientras se escriben importes/kilometraje
- antes de abandonar la página
- antes del redirect de login iniciado por servicios-auth.js

DURACIÓN

El borrador dura como máximo 24 horas.

CUÁNDO SE BORRA

Cuando una consulta autenticada genera finalmente el resultado,
el borrador se elimina automáticamente.

AVISO

Después de restaurar se muestra brevemente:

"RECUPERAMOS LOS DATOS DE TU CONSULTA."

NO MODIFICA

- app.js
- fórmulas
- créditos
- consumo de consultas
- planes
- pagos
- Worker
- SQL
- D1
- Google OAuth
