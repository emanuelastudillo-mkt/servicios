FACIL AUTO — PLANES + REFERIDOS v1.5.12

QUÉ AGREGA
1. Panel de administrador:
   - FREE siempre activo.
   - STANDARD activable/desactivable.
   - PRO activable/desactivable.
   - REFERIDOS activable/desactivable.
   - Recompensa configurable; valor inicial 20 consultas.

2. Mi Cuenta:
   - Solo muestra los planes habilitados.
   - Si Standard y PRO están desactivados, informa que solo está disponible Free.
   - Si Referidos está activo, cada usuario ve su enlace personal.

3. Referidos:
   - El usuario que invita recibe 20 consultas adicionales por defecto.
   - Solo se acredita cuando se registra una cuenta Google NUEVA.
   - Una cuenta referida solo puede generar una recompensa una vez.
   - No permite autorreferido.
   - Los créditos van a bonus_credits.
   - NO cuentan como consultas compradas.

4. Páginas públicas de planes:
   - Standard/PRO se ocultan cuando están desactivados.
   - Los enlaces de Mercado Pago correspondientes también se ocultan.
   - Si Referidos está activo aparece una tarjeta de Referidos.

ESTADO INICIAL TRAS EL SQL
- FREE: activo
- STANDARD: desactivado
- PRO: desactivado
- REFERIDOS: activo
- Premio: 20 consultas

Luego podés cambiarlo cuando quieras desde admin.html.

==================================================
CÓMO FUNCIONA UN REFERIDO
==================================================

1. Usuario A abre Mi Cuenta.
2. Copia su link personal:
   https://emanuelmkt.com.ar/facilauto/?ref=CODIGO
3. Usuario B, que todavía NO tenía cuenta, entra desde ese link.
4. Usuario B inicia sesión con Google.
5. El Worker verifica que sea una cuenta nueva.
6. Se registra el referido.
7. Usuario A recibe +20 bonus_credits.

Si Usuario B ya tenía cuenta:
NO se acredita.

Si se intenta usar el propio código:
NO se acredita.

Si el mismo Usuario B vuelve a usar el link:
NO se acredita de nuevo.
