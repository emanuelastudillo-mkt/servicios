Automatización con cron

El sitio no necesita que el navegador haga scraping. Lo correcto es actualizar las fuentes del lado del servidor y publicar datos ya normalizados. Así evitamos CORS, lentitud y que una caída externa rompa la calculadora.

# Cada lunes 04:00 — tasas\n0 4 * * 1 cd /ruta/autocierre && /ruta/venv/bin/python tools/update_rates.py\n\n# Día 2 de cada mes 04:30 — DNRPA\n30 4 2 * * cd /ruta/autocierre && /ruta/venv/bin/python tools/update_dnrpa.py
04

Qué todavía no está automatizado

El PDF mensual de valores de mercado se carga manualmente porque el origen puede cambiar y porque conviene revisar el documento antes de reemplazar toda la base. El módulo de seguro queda reservado para una siguiente versión.
