# 48 escudos originales

Ilustraciones SVG originales de Apex1000, inspiradas en materiales cromados, esmaltes y formas de emblemas automotrices. Cada símbolo tiene un trazado propio; no son logotipos de fabricantes. Tamaño escalable, fondo transparente. Fuente reproducible: `scripts/build-shields.mjs`. IDs estables del 1 al 48.
