# Terreno del tutorial

`tutorial-terrain-v1.png`: fondo original generado con imagegen a partir de la
referencia estética aportada y la composición del visor existente.
2020 × 779 px, PNG opaco, 3.683.712 bytes. Región ficticia, sin uso cartográfico real.
Contiene sólo terreno: etiquetas, camino, campamentos y equipos se dibujan en SVG.
Se copia desde la salida original conservada en `.codex/generated_images/`;
ningún enlace del juego depende de esa carpeta.

Dirección visual, plantilla y prompt exacto: `../../docs/mapas/`.
No se distribuye la imagen de referencia de otro videojuego.
El service worker de `tutorial/` incluye este fondo para la reapertura offline.
