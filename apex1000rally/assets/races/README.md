# Logos de carreras

32 emblemas originales SVG, 128 × 144, con entorno predominante calculado por kilómetros y bandera del país de largada. El trazado pequeño es decorativo, no un mapa.

Banderas: flag-icons 7.3.2, https://github.com/lipis/flag-icons, MIT. Fuentes y licencia en ../race-flags/. No se descargan banderas durante el juego.

Regenerar: node scripts/build-race-logos.mjs. No modifica premios, distancias, calendario, Sheets ni simulación.
