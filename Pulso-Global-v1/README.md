# Pulso Global - paquete para GitHub Pages

Subí todos los archivos de esta carpeta a la raíz de un repositorio. Después activá GitHub Pages desde **Settings > Pages > Deploy from a branch**, seleccionando `main` y `/ (root)`.

El juego no necesita base de datos ni servidor. Las partidas se guardan localmente en el navegador. El menú `•••` permite exportarlas como JSON para conservar una copia o moverlas a otro dispositivo.

Esta versión 2 incorpora mapa mundial, microgestión por ministerio, subsidios, stock de materias primas y diecinueve construcciones con avance mensual. Los eventos aleatorios están desactivados para facilitar la prueba del motor base.

Los perfiles de figuras públicas y los valores iniciales son abstracciones para una simulación hipotética, no evaluaciones ni estadísticas oficiales.
